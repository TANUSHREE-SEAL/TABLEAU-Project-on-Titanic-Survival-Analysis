# TABLEAU-Project-on-Titanic-Survival-Analysis
🚢 Titanic Survival Analysis — Tableau Dashboard

An interactive Tableau dashboard exploring survival patterns aboard the Titanic, based on passenger class, gender, age, family size, and embarkation point.

📊 Overview

This dashboard analyzes the classic Titanic passenger dataset (2,257 records) to answer one core question: what factors influenced who survived?

Key metrics at a glance:

Metric	Value
Total Passengers	2,257
Total Survivors	1,000
Survival Rate	44.31%
Average Age	29.92
Average Fare	$33.39

🔍 Dashboard Sections

Survival by Gender — compares survival counts between male and female passengers
Survival by Passenger Class — survival rate across 1st, 2nd, and 3rd class
Age Distribution — histogram of passenger ages
Passenger x Gender — heatmap crosstab of survival rate by class and gender
Family Size Analysis — survival rate trend by number of family members aboard
Embarked Analysis — passenger counts and survival split by port of embarkation (Southampton, Cherbourg, Queenstown)

💡 Key Findings

Gender was the strongest predictor of survival — women survived at far higher rates than men, consistent with the "women and children first" evacuation policy.

Passenger class mattered significantly — 1st class had a ~73% survival rate vs. ~29% for 3rd class.

Small families fared best — survival rate peaked for families of 3–4, dropping off for solo travelers and larger groups.

Southampton was the dominant departure port by passenger volume.
